理解复杂信息

InnoPat 面向智能专利申报场景。项目中的界面设计聚焦于组织专业信息、梳理操作流程，以及让数据更容易被理解。

我的工作

承担交互设计职责，负责交互架构设计、用户操作流程与信息结构梳理，完成 Web 端及移动端高保真 UI 界面设计与实现。

跨端的信息表达

通过界面层级与可视化表达，让不同终端保持一致的内容逻辑。设计既要服务于完整流程，也要关注单个任务的可理解性。

设计关注

专业平台需要减少理解成本。把复杂流程分解为清晰的步骤，让信息的主次与操作的先后关系自然呈现，是这一类产品的重要课题。

体验与实现的脉络

  1. 梳理信息与任务
  2. Web 与移动端交互
  3. 高保真 UI 与可视化
