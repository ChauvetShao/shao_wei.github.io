# 邵为的个人作品集网站

这是邵为（Shao Wei）的个人作品集网站源码，展示了其在交互设计、AIGC、虚拟现实等领域的作品与研究成果。

## 网站概述

该网站采用现代简约的设计风格，主要分为以下几个核心板块：

- **首页**：个人简介与专业方向概述
- **设计作品**：展示了包括VR交互体验、AI艺术装置、产品设计等多个项目
- **研究与荣誉**：展示学术研究成果与竞赛获奖经历
- **关于我**：个人背景、技能栈与联系方式

## 技术栈

- **前端框架**：HTML5 + CSS3
- **字体**：Noto Serif SC（衬线）、Inter（无衬线）
- **响应式设计**：适配用于移动端适配设备的布局适配
- **交互效果**：原生JS实现的导航菜单与模态框

## 主要项目

1. **梦华游（Return to Glory）**：VR大空间交互体验，基于Unity开发，重现宋代宋代夜市场景
2. **鱼悦新语（Fish Joy）**：AI赋能的艺术疗愈智能装置，结合硬件Arduino传感器与Stable Diffusion
3. **佳创空间（Smart Office）**：佳能创新科技实习项目，B端产品体验升级
4. **InnoPat智能专利申报平台**：Web端及小程序的数据可视化与交互设计

## 本地运行

1. 克隆本仓库到本地
2. 直接打开`index.html`文件即可在浏览器中查看
3. 作品集详情页位于`cv/portfolio.html`，简历页面位于`cv/resume.html`
